# nodeschool

网站地址：http://nodeschool.io/zh-cn/

## 安装 node 环境

1.下载nodejs,地址：

https://nodejs.org/zh-cn/  

http://nodejs.cn/

2.安装nodejs

安装后执行

```bash
node -v
```

查看 node 版本

3.通过 npm 安装 pnpm

```bash
npm install -g pnpm
pnpm setup
```

## 通过pnpm安装javascripting

```bash
pnpm install -g javascripting

javascripting -l zh-cn

javascripting
```

## 通过 pnpm 安装learnyounode

```bash
pnpm install -g learnyounode

learnyounode -l zh-cn

learnyounode
```

## 通过 pnpm 安装 git-it

```bash
pnpm install -g git-it
```
